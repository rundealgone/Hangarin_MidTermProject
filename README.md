## Features
- **Dashboard** — Live summary cards: total, completed, pending, overdue, this-year tasks, completion rate
- **Tasks** — Full CRUD with status, category, priority, deadline
- **Subtasks** — Break tasks into smaller steps
- **Notes** — Attach notes to any task
- **Categories & Priorities** — Full CRUD management
- **Search** — Filter by title, description, or category
- **Sorting** — Sort by title, date created, deadline, or status
- **Pagination** — 10 items per page on all list views
- **Admin Panel** — Fully configured with search, filters, custom displays
